Google Tasks Importer

Problem

Planning happens in notes, but tasks live in Google Tasks, so moving a plan over means retyping every item by hand.

What it does

Turns a Markdown task list into organized Google Tasks. Headings become parent tasks and bullet points become subtasks, in order. Includes a dry-run preview, duplicate detection, and a safe mode so nothing is overwritten by accident.

Python · Google Tasks API · OAuth · 55 automated tests
